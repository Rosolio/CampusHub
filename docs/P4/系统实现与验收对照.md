# 系统实现与验收对照

## 1. 代码基线

本对照基于 `dev` 分支源码（HEAD: `c6e4d46`），已合并至 `main`。

### 1.1 后端实现结构

- 认证与用户：`AuthController`、`UserController`
- 任务与订单：`TaskController`、`TaskService`
- 智能推荐：`TaskRecommendationService`（100 分制多维打分）
- 评论与互动：`TaskCommentController`
- 评价与信用：`TaskReviewController`
- 消息通知：`MessageController`（含批量已读 `PUT /messages/read`）
- 校园认证：`VerificationController`（证件上传、管理员审核/驳回/撤销）
- 反馈与仲裁：`FeedbackController`
- 后台管理：`AdminController`、`AnnouncementController`
- 安全支撑：`UserVO`（防密码泄露）、`JwtUtil`（token type claim）、`JwtAuthenticationFilter`（角色鉴权）、`SecurityConfig`（`/admin/**` 需 ADMIN 权限）、`GlobalExceptionHandler`（403 支持与 SLF4J 日志）
- 安全加固（commit `62aa029`）：移除第三方登录、注册限频修复、token type 校验、密码哈希泄露修复、角色鉴权、管理员路径保护
- 性能优化（commit `81fc2dc` 起）：服务端分页 + SQL 条件下推、Redis 参数化缓存、关联子查询替代全表 GROUP BY、消息 UNION ALL 替代 OR 条件、复合索引

### 1.2 前端实现结构

- 登录注册：`Auth.vue`
- 首页与任务流：`HomeGateway.vue`、`Discovery.vue`（双 Tab：需求广场 + 话题广场，智能推荐展示）
- 话题广场：`TopicSquare.vue`
- 详情页：`RequestDetail.vue`（loading 状态防布局闪烁）
- 发布页：`Publish.vue`
- 消息中心：`Messages.vue`（智能轮询未读计数，批量已读）
- 个人中心：`Profile.vue`（我的需求 / 话题帖 / 服务三 Tab，胶囊按钮）
- 评价页：`TaskReviewPage.vue`
- 反馈页：`FeedbackPage.vue`
- 校园认证：`VerificationPage.vue`
- 独立页面：`UserAgreementPage.vue`（`/agreement`）、`PrivacyPolicyPage.vue`（`/privacy`），无需登录
- 管理后台：`frontend/src/pages/admin/*`

### 4.1 后端

- JaCoCo 行覆盖率：>= 61%

### 4.2 前端

- `npm run build`：通过
- `npm run lint`：通过

### 4.3 性能优化

- 社区首页：全表扫描 → 20 行索引查询 + 关联子查询
- 消息查询：OR 条件 → UNION ALL，两分支独立走复合索引
- 标记已读：N 次 HTTP → 1 次批量请求
- 消息轮询：5 秒全量 → 5 秒轻量未读计数，变化时再拉
- 个人中心：N+1 评价查询 → 单次批量查询
- Redis 缓存：单 key `tasks:all` → 参数化 `tasks:feed:{queryHash}`

### 4.4 安全加固

- 第三方登录已移除
- `UserVO` DTO 防止密码哈希泄露
- JWT token type claim（access/refresh 区分）
- `JwtAuthenticationFilter` 基于数据库角色鉴权
- `SecurityConfig` 保护 `/admin/**` 路径
- `GlobalExceptionHandler` 支持 403 响应与 SLF4J 日志
- 登录限频（5 次/15 分钟，Redis 实现）

### 4.5 代码质量

- `mvn -B checkstyle:check`：通过
- Checkstyle 违规数：0
