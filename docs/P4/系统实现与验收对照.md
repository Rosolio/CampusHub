# 系统实现与验收对照

## 1. 代码基线

本对照基于 `main` 分支源码（已合并 `dev` 15 个 commit，2026-06-07）。

### 1.1 后端实现结构

- 认证与用户：`AuthController`、`UserController`、`VerificationService`
- 任务与订单：`TaskController`、`TaskService`、`TaskFavoriteMapper`
- 评论与互动：`TaskCommentController`、`TaskCommentService`
- 评价与信用：`TaskReviewController`、`TaskReviewService`
- 消息通知：`MessageController`、`NotificationController`、`NotificationService`
- 搜索推荐：`SearchController`、`TaskRecommendationQuery`
- 文件上传：`FileController`
- 反馈与仲裁：`FeedbackController`、`AdminService`
- 后台管理：`AdminController`、`AnnouncementController`
- 支撑能力：`SecurityConfig`、`JwtAuthenticationFilter`、`GlobalExceptionHandler`、`TaskModeResolver`

### 1.2 前端实现结构

- 登录注册：`frontend/src/pages/Auth.vue`
- 首页与任务流：`HomeGateway.vue`、`Discovery.vue`、`RequestDetail.vue`
- 话题广场：`TopicSquare.vue`
- 发布页：`Publish.vue`（含 `ImageUploader.vue` 组件）
- 搜索页：`SearchResults.vue`
- 消息中心：`Messages.vue`
- 通知页：`Notifications.vue`
- 个人中心：`Profile.vue`
- 评价页：`TaskReviewPage.vue`
- 反馈页：`FeedbackPage.vue`
- 管理后台：`frontend/src/pages/admin/*`
