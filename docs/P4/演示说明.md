## 3. 核心演示路径

### 第一段：学生端主流程（P0）

1. 登录（`/auth`）
2. 浏览首页（`/home`）— 智能推荐排序 + 需求/话题双 Tab
3. 发布任务（`/publish`）— 含分类、地点、时间、奖励
4. 查看详情（`/detail/:id`）— 含进度条和履约步骤
5. 接单、完成确认
6. 评价（`/detail/:id/review`）— 双向互评 + 积分结算

### 第二段：社区互动（P1）

7. 话题广场（`/home?tab=topic`）— 分类筛选 + 关键词搜索
8. 话题详情— 评论、回复、点赞
9. 消息中心（`/messages`）— 会话列表 + 未读标记
10. 个人中心（`/profile`）— 我的需求/话题帖/服务三 Tab

### 第三段：校园认证 + 管理后台（P2）

11. 校园认证（`/verification`）— 上传证件照片 + 提交申请
12. 管理后台（`/admin`）— 数据概览、内容审核、认证审核

### 第四段：性能展示

13. 首页加载 — 分页查询 + Redis 缓存（2-3ms 响应）
14. 消息页 — UNION ALL 索引查询 + 智能轮询
15. 个人中心 — 批量评价查询（非 N+1）

## 4. 亮点

| 特性 | 说明 |
|------|------|
| 智能推荐 | 100 分制多维打分（分类、位置、时间、历史偏好、新鲜度），推荐理由可解释 |
| 校园认证 | 证件上传 → 管理员审核 → 全站"已认证"徽章 |
| 性能优化 | 全表扫描 → 索引分页；OR → UNION ALL；N+1 → 批量；全量轮询 → 计数轮询 |
| 安全加固 | JWT type claim、UserVO 防泄露、角色鉴权、登录限频、XSS/CSRF 防护 |
| CI/CD | GitLab CI + GitHub Actions 双流水线（checkstyle → test → build） |
