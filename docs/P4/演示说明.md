# 演示说明

## 1. 演示目标

展示校园互助平台的核心业务闭环，证明系统已具备 P4 阶段的最小可运行版本。

## 2. 环境准备

### 2.1 本地依赖

- Node.js 20+
- Java 17+
- Maven 3.9+
- MySQL 8+
- Redis 6+

### 2.2 启动方式

推荐直接使用仓库根目录脚本：

```bash
./start.sh
```

也可分开启动：

```bash
cd backend
mvn spring-boot:run

cd frontend
npm install
npm run dev
```

## 3. 测试账号

基于 `backend/src/main/resources/data.sql`，可使用：

- 普通用户学号：`20230001`
- 密码：`123456`

后台管理员账号在初始化脚本中存在 `admin` 用户，但课堂演示建议优先使用普通用户链路，再补充管理端界面展示。

## 4. 核心演示路径

### 4.1 主流程

1. 进入登录页，使用测试账号登录
2. 浏览首页或话题广场
3. 进入发布页，发布一个任务（支持图片上传）
4. 使用另一用户接单
5. 进入任务详情，确认完成
6. 跳转评价页提交评分
7. 进入消息中心查看通知
8. 在个人中心查看任务记录或积分变化

### 4.2 社区流程

1. 进入话题广场
2. 查看话题详情
3. 发表评论或回复
4. 查看消息提醒与互动结果

### 4.3 管理端辅助演示

1. 进入 `/admin`
2. 展示概览、用户管理、内容审核等页面
3. 说明后台接口与页面已具备基本骨架

## 5. 推荐演示顺序

### 5.1 第一段：学生端主流程

- 登录
- 发布任务
- 接单
- 完成
- 评价

### 5.2 第二段：消息与积分反馈

- 查看消息中心
- 查看个人资料或积分变化

### 5.3 第三段：社区与后台

- 话题评论
- 管理端页面

## 6. 现场可能被问到的问题

| 问题 | 建议回答 |
|---|---|
| P0 功能是否全部实现？ | 注册登录、任务发布、接单、完成、评价、消息链路已打通 |
| 是否有测试？ | 后端 `70` 个测试已通过（10 个测试类），前端 build/lint 也已通过 |
| 是否支持管理后台？ | 已有 `/admin` 路由和对应后端接口，具备基础管理能力 |
| CI 是否完善？ | 已有 GitLab CI 基础配置，但自动测试与覆盖率统计仍需补强 |

## 7. 演示风险提示

- 后端测试和运行依赖本地 MySQL 与 Redis
- 若现场环境未准备依赖，优先演示已部署地址或录屏
- 若只做本地演示，建议提前确认 `8080` 和 `5173` 端口可用

## 8. 结论

当前版本适合演示“一个完整可走通的校园互助流程”，不适合在课堂现场临时展开大量配置排障。演示应聚焦主流程和已验证能力。
