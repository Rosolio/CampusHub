# SECII CampusHub

CampusHub 是一个面向校园场景的互助服务平台，支持信息发布、需求匹配、交流互动与后台管理。

## 项目结构

- `frontend`：前端应用代码
- `backend`：后端服务代码
- `docs`：课程文档与阶段交付物
- `refs`：项目阶段说明与参考材料
- `start.sh` / `stop.sh` / `restart.sh`：项目运行脚本
- `deploy.sh`：部署脚本

## 目录说明

- 用户端与管理端页面相关内容位于 `frontend`
- 接口、业务逻辑与数据访问相关内容位于 `backend`
- 需求分析、设计说明、测试记录等文档位于 `docs`

如需查看更具体的实现或文档，请进入对应目录阅读。
